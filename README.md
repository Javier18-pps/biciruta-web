# BiciRuta

Página web de la tienda de bicicletas BiciRuta S.L. Proyecto de la práctica UT1 de Lenguajes de marcas (ASIR).

## Estructura

- index.html: estructura y contenido de la página
- css/estilos.css: estilos
- js/app.js: comportamiento
- img/logo_biciruta.png: logotipo
- README.md y .gitignore

## Cómo verlo

Abre la carpeta en VS Code, instala la extensión Live Server y pulsa "Go Live".
